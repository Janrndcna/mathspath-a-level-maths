# MathsPath — A-level Maths self-study

A free, browser-based A-level Mathematics practice app with topic folders, worked explanations, progressive hints, flashcards and original practice papers.

## Student data

The app is static. Practice progress is stored in the learner's own browser and is not sent to a server. Question content is public in this repository.

## Updating the site

Sign in to GitHub as the owner, open the `mathspath-a-level-maths` repository, and replace `index.html` (plus `robots.txt` or `sitemap.xml` when needed). GitHub Pages publishes updates from the `main` branch.
