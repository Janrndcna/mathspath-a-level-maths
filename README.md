# MathsPath — A-level Maths self-study

A free, browser-based A-level Mathematics self-study app. Open **Topic folders**, choose Pure Mathematics, Statistics or Mechanics, then open a topic and subtopic to pick a worked practice question. The first learning-path section is now called **A-level foundations**.

The updated library contains 22 topics, 65 subtopics and 190 practice questions, including 44 additional questions with worked steps. Question feedback, hints, flashcards, the learning pathway and practice papers remain part of the prototype.

## Student data

The app is static. Practice progress is stored in the learner's own browser and is not sent to a server. Question content is public in this repository.

## Updating the site

To publish a future update, sign in to GitHub as the owner, open the `mathspath-a-level-maths` repository, choose **Add file → Upload files**, and select the replacement `index.html` (and any related files being changed). Commit the change to the `main` branch. GitHub Pages then publishes it automatically, usually within a few minutes. The live site is https://janrndcna.github.io/mathspath-a-level-maths/.

For a content-only update, keep the existing `robots.txt`, `sitemap.xml`, `.nojekyll` and Google verification file in the repository. Student progress is stored in each learner's browser, so replacing the site does not move progress between devices.
